# Game Studio — New_Game

코딩을 몰라도 템플릿을 고르고 글자와 색상을 바꿔 나만의 간단한 브라우저 게임을 만들 수 있는 노코드 게임 제작 도구입니다.

## 포함된 기능
- 클릭 게임, 퀴즈 게임, 반응속도 게임, 2D 플랫포머 템플릿
- 플랫포머: 키보드/터치 이동, 점프, 코인 수집, 깃발 도착
- 2D 맵 편집기: 블록·레이저·코인·가시 배치, 선택/드래그 이동, 크기·색상 변경, 삭제 및 기본 맵 복원
- 편집한 2D 맵은 브라우저에 자동 저장되고 HTML 내보내기에도 반영
- 게임 제목, 설명, 제한 시간, 색상, 시작 버튼 수정
- 실시간 미리보기와 직접 플레이
- 설정 자동 저장(현재 브라우저)
- 완성한 게임을 독립 실행 HTML 파일로 다운로드
- 모바일/태블릿/PC 반응형 화면

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages 배포
1. 저장소의 **Settings**로 이동합니다.
2. **Pages**를 엽니다.
3. **Deploy from a branch**를 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`로 설정하고 저장합니다.
5. 배포가 완료되면 Pages 주소에서 Game Studio를 사용할 수 있습니다.

> 현재 버전은 템플릿 기반의 간단한 제작 도구입니다. 드래그 앤 드롭 맵 편집기, 캐릭터/장애물 배치, 프로젝트 클라우드 저장 기능은 아직 포함되어 있지 않습니다.


## Firebase 공개 게임 설정
저장 게임의 기본 공개 설정은 비공개입니다. 게임 카드의 **공개하기**를 누르면 글로벌 맵에 나타나며, **비공개로 변경**하면 글로벌 맵에서 제거됩니다.

Firebase Console → Firestore Database → Rules에서 저장소의 `firestore.rules` 파일 내용을 붙여넣고 **게시**해야 합니다. 이 규칙은 각 사용자의 개인 게임을 본인만 읽고 수정하도록 하고, `publicGames` 컬렉션은 로그인한 사용자에게만 읽기를 허용하며 공개 게임의 소유자만 등록·수정·삭제할 수 있게 합니다.
